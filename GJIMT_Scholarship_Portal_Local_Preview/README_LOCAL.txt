GJIMT SCHOLARSHIP PORTAL — LOCAL PREVIEW
========================================
RUN ON WINDOWS
1. Extract this ZIP.
2. Open the extracted folder.
3. Double-click index.html (the lowercase file in the main folder).
4. Use Chrome or Edge.

DEMO ADMIN LOGIN
Username: admin
Password: GJIMT@2027!Demo

LOCAL PREVIEW FEATURES
- Welcome page, student registration form and validation
- Percentage and scholarship slab calculation (marks out of 800)
- Voucher preview/print
- Browser localStorage for registrations
- Admin dashboard, filters, search and CSV export

IMPORTANT
This is only a local preview. Student registrations stay in this browser on this computer.
No data is sent to Google Sheets. WhatsApp and email messages are not sent.
The demo admin password is not for a public/live website.
For live operation, deploy the original Apps Script source files in Apps_Script_Original.

If index.html appears unstyled, keep index.html and app.js together in the same folder and open index.html again in Chrome/Edge.
